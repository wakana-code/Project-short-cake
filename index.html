🔑 STEP 1: GitHubと接続する(初回のみ)

ShortCakeはあなたのブラウザから直接GitHubを操作します。そのための「合鍵」(Personal Access Token)を1回だけ作ってもらいます。3分で終わります。

  1. ここをクリックしてGitHubのトークン作成ページを開く(要ログイン)
  2. Token name: shortcake と入力
  3. Expiration: 90 days のままでOK(切れたらまた作ればOK)
  4. Repository access: All repositories を選択
  5. Permissions → Repository permissions を開き、次の4つを Read and write にする:
    ✅ Administration(リポジトリ作成用)
    ✅ Contents(ファイルアップ用)
    ✅ Pages(公開設定用)
    ✅ Workflows(自動ビルド用)
  6. 一番下の Generate token を押す
  7. 表示された github_pat_... で始まる文字列をコピーして、下に貼る

🔒 トークンはあなたのブラウザ(localStorage)にのみ保存され、外部には一切送信されません(通信相手はgithub.comだけです)。心配になったらGitHub側でいつでも無効化できます。

🔌 接続解除

トークンをこのブラウザから削除します。
